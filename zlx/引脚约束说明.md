## 二、三个必须注意的坑

1. **BANK_3 是 1.5V，不是 3.3V。** 手册 3.2.3 表写明 `VCCO3 = 1.5V`，因此按键 SW1~SW4、复位 SW5 所在 bank 的 `IO_TYPE` 必须是 `LVCMOS15`、`BANK_VCCIO=1.5`。手册 3.2.6 的 LED 表把 BANK_3 的电平写成 3.3V，属于手册笔误——LED 也在 BANK_3，实际 1.5V。若照手册 LED 表写 `LVCMOS33`，综合能过但上板电平不匹配。

2. **SW4（T20）不能当普通 IO 用。** 它是 PG484 封装的 SSPI 复用/专用脚，实测布线报错：
   ```
   ERROR (PR2017): 'key_in[3]' cannot be placed according to constraint, for the location is a dedicated pin (SSPI)
   ```
   顶层本来就没有用 K4（`key_in[3]` 被综合优化掉，另有 `WARN (CV0018) Input key_in[3] is unused`），所以文件里把这两行注释掉即可。以后确实要用 K4，需要在工程设置的 Dual-Purpose Pin 中把 SSPI 设为 "use as regular IO"。

3. **串口两根线以网络名为准。** 手册 3.2.7 那张表的"描述"列写的是 CH340 一侧的名字，与网络名正好相反：`B2_35A_K20_TXD`（K20）是 FPGA 的 TXD，`B2_35A_L20_RXD`（L20）是 FPGA 的 RXD。约束文件按网络名给：`uart_tx = K20`、`uart_rx = L20`。若上板出现"能发不能收"，把两行对调即可。

## 三、使用方法

1. 把 [`DLB.cst`](DLB.cst)（和可选的 [`DLB.sdc`](DLB.sdc)）复制到工程目录 `D:\gowin_software\DLB\src\` 下；
2. 云源中 `Project → Add File` 加入这两个文件，双击 `.cst` 可在 FloorPlanner 里看到引脚分布；
3. 直接 `Synthesize → Place & Route` 即可；`.sdc` 只是让时序分析有 50MHz 的参考时钟，不要时序分析也可以只用 `.cst`。

数码管若是外接 74HC595 模块，飞线后把文件"八、8 位 74HC595 数码管"一节的三行取消注释，填入实测管脚即可。

## 四、实测验证结果

用本机云源 V1.9.12.03 命令行（`gw_sh`）把 16 个源文件 + 本约束文件从头跑了一遍综合与布局布线：

* 综合、布局布线、**位流生成全部通过**，所有 `IO_LOC` 均按表中管脚落地（见 `impl/pnr/project.rpt.txt` 的管脚报告）。
* 去掉 `key_in[3]`（T20）后无任何 ERROR/WARN。
* 加上 [`DLB.sdc`](DLB.sdc) 的 `create_clock -period 20` 后有时序报告：**当前设计在 50MHz 下不满足时序**，实际 Fmax ≈ **21.98 MHz**，117 个建立时间端点违规，TNS = −826 ns。瓶颈是 `Test.v` 里的 `count_abs % 32'd10000`（除以常数的组合逻辑，数据延迟约 45ns）馈入 `Seg8` 的 BCD 转换，关键路径 `position_sample → Seg8_inst/binary_shift_*`。
  这不是管脚约束的问题，属于 RTL 层面：可以改成十进制逐位减法/移位加 3 转换，或先把 `%10000` 的结果打一拍寄存，也可以直接给 `Seg8` 送 `run_state*10000 + count_abs`，让 `Seg8` 自己完成十进制拆分。

## 五、换通道 / 改方向

* 电机想用 B 通道（XH2）：把 `tb_pwm/tb_in1/tb_in2` 换成 `V14/AA17/V15`，编码器换成 `enc2 = W18/W17`（手册 3.3.3、3.3.4），并相应修改顶层例化。
* 编码器计数方向反了：改顶层参数 `ENCODER_DIR_REVERSE = 1`；电机转向反了：`MOTOR_DIR_REVERSE`（当前为 1）。
* 其余可用但本设计未用的板载管脚（LED `U18/U19/U17/T17`、拨码 `W20/V20`、27MHz `B20`、ADC 超量程 `F18`）已在 `.cst` 末尾以注释形式列出，需要时取消注释并改名即可。
