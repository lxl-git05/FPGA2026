# Block Studio · FPGA 模块构思工作台

双击 **`dist/block-diagram-editor.html`**，使用 Chrome 或 Edge 打开。无需安装 Node.js、启动服务、联网或登录；整个编辑器已打包进单个 HTML，可单独复制到其他电脑。

## 使用流程

1. 点击左侧“自定义模块”，在右侧修改名称、颜色、尺寸及说明。
2. 点击“编辑端口 / 批量添加”，配置 `input`、`output`、`inout`，以及名称、位宽、所在边和位置。位置留空自动排列，填写百分比可微调；同侧端口可上移排序。
3. 从端口圆点拖到另一个端口进行连接。选中连线后可编辑信号名、标签沿线位置；拖动控制点或线段调整直角走线。
4. 同一输出可以连接多个输入。需要分支黑点时，选中连线并点击“在线上插入分支连接点”，再从黑点引出信号。两条线交叉不自动连接。
5. Shift 点击或框选同层模块，点击“封装模块”。穿过边界的信号自动生成父模块端口，内部连接完整保留。双击封装模块展开/折叠；移动父模块会带动内部结构，内部元件超出边界时外框自动扩展。
6. 选中展开的封装模块后添加基础元件，新元件会放入内部。父模块输入在内部作为信号源；跨层连接必须经过父模块端口。解除封装时，边界接口映射转换为分支点以保留连通关系。
7. 选中模块，点击“保存到我的模块”或“导出模块包”。每次导入/添加都生成独立副本，不会联动修改其他实例。

批量端口示例：

```text
input clk 1
input rst_n 1
input data [DATA_WIDTH-1:0]
output done 1
output data_out 8
```

模块库中的模块点击即可加入画布。内置 UART 发送系统、按键消抖两个示例工程。

## 保存与导出

| 文件 | 用途 |
| --- | --- |
| `*.fpga-diagram.json` | 完整工程：模块、端口、网络、封装关系、布局、样式及视图位置 |
| `*.fpga-module.json` | 单个模块及其所有内部结构；可跨工程导入 |
| PNG | 1× / 2× / 4× 图片，白底或透明背景 |
| SVG | 可放大的矢量图片，适合报告和文档 |

“打开工程”替换画布；“导入模块”将模块加入当前画布和模块库。图片可导出整个工程或单个选中模块，反映当前展开/折叠状态。图片不作为可编辑工程文件，继续修改请保留 JSON。

浏览器会尝试保存草稿和模块库，下次打开可恢复。浏览器清理数据、改变文件位置或使用其他浏览器时，草稿可能不可用；请用“保存工程”和“导出模块包”作正式备份。保存采用浏览器下载，重复保存可能产生带编号的文件，由浏览器的下载设置决定位置。

## 快捷操作

| 操作 | 快捷键 / 鼠标 |
| --- | --- |
| 保存工程 | Ctrl+S |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z（或 Ctrl+Y） |
| 复制 / 粘贴 | Ctrl+C / Ctrl+V，保留选中模块之间的连接 |
| 封装 | Ctrl+G |
| 删除 | Delete，确认后可撤销 |
| 多选 | Shift 点击 / Shift 框选（也支持 Ctrl 点击） |
| 画布平移 | 右键或鼠标中键拖动 |
| 缩放 / 适应画布 | 滚轮 / F |

输入框内优先保留文字编辑快捷键。

## 连接规则与边界

- 拒绝两个输入或两个输出直接连接、重复连接、网络多输出驱动，以及已知整数位宽冲突。
- `8` 与 `[7:0]` 均表示 8 位。符号位宽只保存为文字，不求值；相关连线以虚线显示“待检查”。
- `inout` 可以连接，但不验证三态使能、总线仲裁或时序；反馈连接允许存在。
- 这是结构构思工具，不进行 HDL 解析、代码生成或逻辑仿真。
- 默认直角走线，复杂交叉可手动调整拐点；首版不承诺全图自动避障布局。
- 模块模板采用独立副本，不提供库定义同步升级，也不直接读写 draw.io 格式。
- 导入文件版本为 `schemaVersion: 1`。导入先验证引用、层级和连接规则，失败不会替换当前工程。

## 开发与验证

源码为 TypeScript，图形引擎为 AntV X6 3.1.8；运行时依赖全部内嵌在 HTML 中。

```powershell
cd D:\github\FPGA2026\FPGA2026\HTML
npm ci --cache ..\Claude_Temp\npm-cache
npm run check
npm test
npm run build
```

- `src/model.ts`：独立数据模型、连接检查、层级封装、模块包和文件读取。
- `src/app.ts`：画布交互、属性、历史记录、本地存储和图片导出。
- `src/examples.ts`：两个内置示例。
- `src/index.html`、`src/style.css`：中文界面和样式。
- `tests/model.test.ts`：模型与文件的自动化测试。
- `tests/run.mjs`：将测试编译到工作区根目录 `Claude_Temp/` 后运行。
- `build.mjs`：将脚本和样式打包为自包含 HTML。

已通过模型测试，并用真实 Chrome 在离线状态验证文件加载、鼠标连线与拒绝非法连接、封装/折叠、整体移动与撤销、复制、模块库、草稿恢复、工程和模块导入、PNG/SVG 导出。第三方声明见 `THIRD_PARTY_NOTICES.md`。
