# TB6612与编码器串口测试

打开`tb6612_encoder.gprj`，顶层为`top`。旧`tb6612_motor_driver.v`、`encoder_quad.v`、`PWM.v`直接引用原文件，不修改其逻辑。电机接J280的XH1；按`Balance_Ctrl_20260618.pdf`第1页，XH1电机线O1/O2连接TB6612 B桥，编码器仍为1A/1B。SW5复位，上电/复位命令为0。

串口选择**115200、8数据位、无校验、1停止位，文本/ASCII发送**。

| 发送文本 | 结果 |
| --- | --- |
| `20` | 顺时针20/2500，约0.8%占空比，不代表20% |
| `1250` | 顺时针50%占空比 |
| `-2500` | 逆时针100%占空比 |
| `0` | 停止 |

CR回车(0D)、LF换行(0A)、CRLF都能立即提交命令，CRLF只执行一次；单独空行忽略，不会被当成0。没有附加换行时，末字节后空闲10ms也会提交。推荐开启“发送新行/CRLF”；无需回车的模式要整串发送，逐字符慢输入可能被空闲判定分成多条命令。连续数字必须用换行或至少10ms空闲分开，例如无分隔的`20`和`1250`会被视作`201250`。

只接受可选`+`/`-`和1~4位十进制数字，范围-2500~2500；空格、非法字符、无数字的符号、过长或越界命令整条拒收，保持之前的PWM，不进行截断或限幅。有效命令持续生效直到下一条命令或复位，没有通信超时自动停机。

每100ms上传一行，无多余前导零，正数和0也带`+`：

```text
enc=+123,delta=-12,pwm=+1250
```

- `enc`：复位以来AB四倍频的有符号净累计位置。
- `delta`：最近100ms窗口的有符号净增量；正负表示该窗口运动方向，不是圈数、角度或绝对边沿总数。
- `pwm`：已接收并生效的有符号PWM计数命令，不是测量的占空比。实际占空比为绝对值/2500，频率20kHz。

三字段同时冻结，发送期间不会拼入新值；UART接收控制与发送遥测独立。行尾显式发送0D 0A。根据实机确认，后续固定顺时针为正，两方向参数`MOTOR_DIR_REVERSE=1`、`ENCODER_DIR_REVERSE=1`；正PWM为IN1=0/IN2=1，原始AB序列00→01→11→10→00改为减计数。旧模块自身默认值与代码均不修改，方向适配只在板级顶层完成。

保留旧模块的32位累计计数、PWM周期边界占空比更新以及即时方向切换行为，没有新增换向死区；位置与速度的物理换算不在本例程内。

`tests/motor_uart_tb.sv`提供真实UART位级收发、命令边界、PWM计数和遥测格式自检。构建与实际仿真、上板测试的完成情况以`Claude_Change.md`本轮记录为准。

## 2026-10-20实机观察与通道映射修正

用户观察：当前顺时针转动时编码器读数减小，期望方向相反，先记录该机械方向关系，未修改`ENCODER_DIR_REVERSE=0`或旧解码模块。以后若统一顺时针为正，可只修改顶层参数为1；电机方向与编码器方向需分别确认。

用户日志`enc=-17,delta=+0,pwm=-1250`说明命令寄存器已接受-1250，上传窗口未检测到位移；pwm字段不是PWM引脚实测值。用户确认拔掉USB后板子仍运行，但这只能证明逻辑供电存在，不能单独证明驱动芯片VM处的12V正常。

原理图中U4的AO1/AO2接O3/O4，BO1/BO2接O1/O2；XH1接O1/O2+1A/1B，XH2接O3/O4+2A/2B。此前根据手册/例程命名将XH1当A桥，现按原理图修正CST为：PWMB V14、BIN1 AA17、BIN2 V15，编码器保持Y20/AA20。官方例程同时驱动两桥，不能用其电机成功转动来证明单桥与连接器对应关系。

本轮仅纠正物理约束和说明，旧电机/PWM/编码器及UART逻辑保持不变。最终是否匹配手中PCB版本仍需重新生成位流下载并实测；若仍不转，检查VM处12V、STBY处3.3V及B桥逻辑输入/电机输出。

## 后续固定方向约定：顺时针为正

2026-10-20用户已确认修正桥通道后电机能转，但原配置下顺时针对应负PWM且编码器计数减小。按用户要求同时将顶层两个方向参数设为1，后续工程沿用此机械正方向，以上一节“先记录、未反转”为调整前历史。

| 机械方向(沿用本次实机观察视角) | PWM命令 | 编码器变化 | 100ms净增量 |
| --- | --- | --- | --- |
| 顺时针 | 正 | enc增加 | delta为正 |
| 逆时针 | 负 | enc减小 | delta为负 |

enc是相对复位零点的累计位置，顺时针只保证数值增加，并不保证数值始终大于0。delta是窗口净增量，窗口内往返运动可能互相抵消。电机仍接XH1，B桥及编码器约束保持不变。新约定需重新下载本轮固件生效；电机/编码器/PWM/UART原模块保持不变。
