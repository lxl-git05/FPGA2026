# 高云倒立摆：模块化双环控制

打开 `DLB.gprj`，顶层为 `Top`。器件 GW2A-LV55PG484C8/I7，50MHz，XH1 使用 TB6612 B桥。
**2026-10-21实测直立基准为2180，已替换设计初稿的3300。** 上电停止，当前配置为单内环、手动起摆。

## 模块关系

可编辑架构图：[architecture.drawio](docs/architecture.drawio)。

| 模块 | 职责 |
|---|---|
| Top | 板级连接、1ms/20ms节拍、LED；不解析字符串或实现启摆算法 |
| board_io | 隔离引脚；封装Key、UART字节、ADC、编码器、电机/PWM |
| adc_frontend | 25MHz ADC转发时钟、62.5µs原始采样、16点平均及窗口有效性 |
| command_rx | ASCII语法→8位ID、signed64微单位、单拍提交 |
| config_bank / gain_convert | 配置唯一写入者、范围检查、定点转换；换周期事务重算系数 |
| safety_guard | 传感器健康、捕获许可、稳摆安全、位置安全及当前故障原因 |
| run_control | 启停状态、原点、故障锁存、PWM来源选择及最高优先级安全门控 |
| swing_up | 当前±50%/150ms双向脉冲、40ms三点峰值判断、捕获与超时 |
| cascade_control | 5ms A环、50ms B环，两个独立分拍PID及完整运算快照 |
| telemetry_tx | 六字段快照、定点转六位小数、UART逐字节发送 |

RTL均为Verilog `.v`。测试台可使用SystemVerilog；硬件不需要浮点IP。控制逻辑只使用50MHz系统时钟，毫秒节拍均为时钟使能。
新工程内 `MyPID.v`复制自PID_Motor分拍版，并补充timescale；历史工程不改。Key、UART字节、电机、PWM、编码器直接引用原文件，复制整个工程时需保留相对目录。

## 单位及控制规律

| 字段 | 单位 |
|---|---|
| A.goal / A.real | 实际应用的整数ADC目标 / ADC反馈 |
| A.set | 带方向的PWM百分比，±100 |
| B.goal / B.real | 相对启动原点的编码器计数，1040计数/圈 |
| B.set | ADC目标修正量，默认±100 ADC码 |

双环：`A目标 = 直立基准 + CASCADE_SIGN × B输出`，当前Top配置 `CASCADE_SIGN=1`。
单环：A目标直接使用直立基准，B输出为0。1040计数/圈描述电机位置，不代表摆杆ADC的角度比例。
PWM/编码器顺时针为正，方向参数均为1。根据用户观察到的内环正反馈，`ANGLE_OUTPUT_SIGN`已由1改为**-1**，只翻转内环输出，串口A.set同步反映该输出。`CASCADE_SIGN=-1`保留；修正后的内环恢复方向及外环级联极性仍需实机验证。

PID_Core保持signed32整数输入、Q16.16增益和72位积分。接受tick后8拍提交，负数取整为算术右移，不保证等于C浮点逐位结果。
控制器另有采样、清历史和调度阶段，整体延迟略高于160ns，完成就提交，不等待下一个5ms/50ms边界。
两环同时到期时先锁存两路反馈/配置，先算B，再让A使用**这次新B输出**。

串口系数使用连续C公式语义，设采样周期为T秒：

```
A: kp_q=round(Kp*25*65536)
   ki_q=round(Ki*T*25*65536)
   kd_q=round(Kd/T*25*65536)
B: kp_q=round(Kp*65536)
   ki_q=round(Ki*T*65536)
   kd_q=round(Kd/T*65536)
```

A内部输出为PWM计数±2500，串口显示除以25后的百分比。B内部输出直接为ADC码偏移。
所有换算采用正负对称四舍五入，整数目标也以相同规则量化。原PID内部的输出取整、积分及输出限幅规则保留。
改增益在下一个对应控制边界清该环历史再计算；改目标保留历史。同拍提交的参数从下一边界使用。

## 初始配置与修改位置

集中在 `src/config_bank.v` 的复位初始化分支；各项实际为运行寄存器，首版无Flash保存。
首版串口只开放八个PID命令。单双环、周期、启摆等全局配置可在初始化处修改；模块已预留统一写接口，尚未把全局配置接口开放到板级串口。

| 配置 | 默认值 |
|---|---|
| dual_loop / auto_start | 1 / 1 |
| center_adc / goal_position | **2180** / 0 |
| period_a_ms / period_b_ms | 5 / 50 |
| capture_adc / fall_adc | ±500 / ±700 |
| kick_percent / kick_ms / judge_ms | 35% / 100ms / 40ms |
| swing_timeout_ms / adc_timeout_ms | 10000 / 3 |
| rail_low / rail_high | 64 / 4032，端点本身也无效 |
| outer_limit_adc / inner_limit_percent | 100 / 100% |
| inner_i_percent / outer_i_adc | 100% / 100 ADC码 |
| travel_counts | 10400，独立于外环目标 |

| 环 | Kp | Ki | Kd | 初始Q系数 |
|---|---:|---:|---:|---|
| A | 0.380000 | 0.000000 | 0.012000 | 622592 / 0 / 3932160 |
| B | 0.000000 | 0.000000 | 0.000000 | 0 / 0 / 0 |

参数从旧FPGA DLB离散参数转换为连续参数，B再按408→1040计数尺度折算，以六位小数作为统一输入精度。
这些是移植初值，不能把时序通过当成机械闭环稳定。`Top.COUNTS_PER_REV`集中设置计数尺度，改变它会同比调整B的默认连续增益及十圈默认行程；串口goal_B始终直接使用计数。
20kHz PWM与50MHz时钟为当前固定硬件约定；如调整频率，需要同时修改百分比与PWM计数的转换比例。

## 状态、死区与保护

K1按下启动/再次按下停止；SW5低有效复位。启动时记录编码器原点，捕获时保持该原点不变。

| 状态 | 输出及转移 |
|---|---|
| STOPPED=0 | PWM0；传感器健康、位置安全、配置转换空闲时，K1允许启动 |
| MANUAL_WAIT=1 | PWM0；等待人工扶入捕获区 |
| AUTO_SWING=2 | 先正负脉冲，再三点峰值判断补充摆动能量 |
| BALANCE=3 | 两环/单环控制，固定直立基准保护 |
| FAULT=4 | PWM0并锁存故障；条件解除后重新按K1才启动 |

连续两次40ms判断位于捕获区且窗口有效，才进入稳摆；原点不变，清两环历史。
稳摆保护：每次内环采样时检查`abs(a_sample_adc-center_adc)>700`，**不是跟随外环修正的A实际目标**。
在当前默认值下，捕获范围1680～2680，稳摆保护范围1480～2880，等于边界允许，超过才停机。
范围保护使用内环每5ms锁存的同一份ADC反馈；快照发布后即检查并覆盖PWM，越界取消该次计算，不等待PID完成。62.5µs原始样本不再直接触发范围保护。电机位置超出相对启动原点±10400计数也会停机，不随goal_B移动安全边界。

ADC实质为10位码左移2位，再平均；原始最大4092，不能把它当作真正12位ADC。
约20°的传感器死区应在机械上移至下垂附近。平均前检查两端码值和窗口跨度≥2048，任何坏样本都会使整个平均窗口无效。
坏窗口显示末次原始码，不发布0与满量程的假中值。完整ADC判定模式（ADC_RANGE_ONLY=0）下，启摆经过死区会清除峰值和捕获历史，稳摆经过无效区会停机；当前调试模式旁路这些有效性门控。
死区无效与采样失鲜不同：持续的端点码仍然产生采样事件。非稳摆时，若原始码位于已配置两端死区，允许该样本伴随OTR，不阻止初始启摆；此例外不让死区参加捕获。
有效ADC区的OTR仍阻止启动/触发故障；稳摆阶段任何OTR均停机，包括端点死区。采样失鲜、行程和启摆超时保护不变。

| fault_code | 原因 |
|---|---|
| 1 | ADC没有就绪或采样失鲜 |
| 2 | ADC超量程OTR |
| 3 | 电机位置越界 |
| 4 | 稳摆角度越界或角度窗口无效 |
| 5 | 自动起摆总超时 |

LED1亮表示运行（含手动等待/起摆），LED2表示稳摆，LED3表示故障。首版故障码保留为明确的内部接口，不混入六字段串口。

## 串口

115200/8N1、ASCII、区分大小写。支持可选符号和最多六位小数，`.5`及`1.`有效，不支持科学计数法。

```
@Kp_A=0.80$#
@Ki_A=0.51$#
@Kd_A=0.49$#
@goal_A=2180$#
@Kp_B=0.80$#
@Ki_B=0.51$#
@Kd_B=0.49$#
@goal_B=1040$#
```

示例用于说明语法，不代表推荐实机参数。完整`$#`才提交，支持拆包、连续帧、新`@`重同步。
每帧含`@/$#`最多32字节，100ms无新字节丢弃残帧，命令外CR/LF忽略，串口助手追加回车换行不影响。
格式、长度、精度、signed64微单位或signed32转换越界时拒收；目标超出有效保护范围也拒收，保持旧值。不发送ACK，不兼容旧Protocol V1。

50Hz发送六字段六位小数、无标签、无多余前导零，结尾真实`0D 0A`：

```
2180.000000,2181.000000,-50.000000,1040.000000,-2.000000,-5.000000
```

代表A目标、A反馈、A输出百分比、B目标、B反馈、B输出ADC偏移。
每次发送冻结两环最近完整结果；5/50ms两环不是同一时刻计算。停止时反馈继续更新、输出为0；单环B输出为0。
启摆PWM不伪装成A PID输出，起摆时A.set为0，电机仍可能在执行启摆脉冲。
格式化与UART发送独立于控制；忙时不排队，当前最大计数字段长度也能在20ms内传完。

## 实机验收次序

先在配置初始化处使用单环、手动起摆，核对2180、ADC方向、PWM方向和±700保护；再启用外环，确认B修正产生恢复作用；最后恢复默认双环自动起摆，验证脉冲、死区和捕获。
测试覆盖范围与当前工具限制详见验证记录。首版无Flash保存、PWM死区补偿、额外滤波或串口启动命令。

## 临时ADC调试模式

当前Top参数`ADC_RANGE_ONLY=1`：暂时忽略OTR、窗口无效、两端无效及采样失鲜判定；首次采样后允许启动，捕获仍需连续两次进入基准±500。稳摆时仅以内环每5ms实际锁存的ADC反馈是否超出基准±700触发ADC停机，当前为1480～2880（含边界）。起摆等待阶段不执行该范围停机。
电机行程、K1停机、自动起摆超时及故障锁存保留。采样与平均算法未改；恢复完整ADC判定时将该参数改为0，重新编译下载。此前描述的完整ADC保护适用于参数为0。

## 外环方向实机调整

按用户反馈，Top的`CASCADE_SIGN`由-1改为+1，当前级联关系为`内环目标 = 直立基准 + 外环PID输出`；此前减法关系为历史配置。内环输出方向`ANGLE_OUTPUT_SIGN=-1`、电机及编码器顺时针为正不变。通用cascade_control模块自身默认值不改，由Top显式传参。

范围检测使用现有1ms/16点采样结果，每5ms取一次，与PID反馈快照完全相同，不是重新计算5ms平均。正常窗口是平均值；无效窗口仍沿用adc_frontend的末次原始码回退，因此不能保证消除所有毛刺。两次内环采样之间的孤立原始越界不触发范围停机；持续越界到下一次采样才被检测，等待约0～5ms。
