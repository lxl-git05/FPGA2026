# PID_Motor：单环位置控制

顶层为 `src/top.v`，器件 GW2A-LV55PG484C8/I7，50MHz。
本工程 MyPID 已按用户确认改为分拍版；原 Key、UART、encoder_quad、tb6612_motor_driver、PWM 源文件保持不变，DLB 工程的 MyPID 也不修改。
工程直接引用 DLB 的电机/编码器/PWM，以及 uart_loopback 的 UART 字节模块；复制工程时需要一起保留这些相对目录。Key 未接入本次业务。

## 上电、方向与单位

上电目标为 0°，持续闭环保持复位位置；SW5 低有效复位，重新清零编码器及 PID。
顺时针为正，顶层 MOTOR_DIR_REVERSE、ENCODER_DIR_REVERSE 均为 1。
COUNTS_PER_REV 默认 1040；CONTROL_MS 默认 20，50Hz 更新。修改参数需重新综合。

目标/反馈对外均为角度，内部为整数编码器计数；请求 78°取最近计数 225，反馈对应 77.884615°。
外部 set 是实际 PID 输出的 PWM 百分比，2500 个 PWM 计数等于 100%；不是角度或第三个增益。
积分贡献上限 ±500 个 PWM 计数，即 ±20%；最终输出上限 ±2500，即 ±100%。

连续 C 参数默认 Kp=0.98，Ki=0，Kd=0.12。顶层自动折算成内部 Q16.16：

```
T = CONTROL_MS / 1000
S = 25 * 360 / COUNTS_PER_REV
kp_q = round(Kp * S * 65536)       // 默认 555796
ki_q = round(Ki * T * S * 65536)   // 默认 0
kd_q = round(Kd / T * S * 65536)   // 默认 3402831
```

换算正负对称四舍五入。原 PID 内部算术右移、积分、输出限幅行为不变，因此不保证与 C 浮点逐位相同。
每个 20ms 边界先锁存目标、反馈和增益，再触发运算。新增益在周期边界先 clear 后 tick；仅修改目标不清积分与历史误差。
PID_Core 接受触发后8个时钟周期（160ns）完成：误差快照、误差差分、并行乘法、积分累加、积分限幅、两级求和、输出限幅、统一提交。完成即拉高 pid_valid 一拍，不等待下一个20ms边界。
运算期间输出保持上次结果，忙时忽略新 tick；复位、clear 或禁用会取消未完成运算，避免旧结果随后提交。输入参数及限幅均在接受触发时冻结。
命令提交与边界同一拍时，新值从下一周期生效。编码器为有符号32位累计值，长时间超范围会按原模块行为回绕。

## 串口

115200，8N1，ASCII 文本，名称区分大小写：

```
@Kp=0.80$#
@Ki=0.51$#
@Kd=0.49$#
@goal_A=78$#
```

数值允许一个可选正负号、整数及最多六位小数；不支持科学计数法。`.5`、`1.`也可接受。
`$#`才提交完整合法命令。支持拆包、连续命令；新 `@`重启接收。帧含 `@`、`$#`最多32字节，接收中字节间空闲100ms丢弃。
命令外 CR/LF 忽略，所以串口助手自动追加回车换行不会影响。命令内部不能插入换行或空格。
格式、长度、整数解析、归一化或最终32位有符号换算溢出时整帧拒收，参数不变。不返回 ACK 或错误文本，不属于既有 Protocol V1。
输入最多六位小数，先归一为微单位64位幅值，再以128位多周期乘除换算；结果必须落在 signed32 范围。

每次 PID 完成后，以冻结快照发送一行：

```
78.000000,77.884615,12.500000
```

依次为请求目标度、同次反馈度、输出百分比；六位小数、无标签、无正号、无多余前导零，末尾真实字节 `0D 0A`。
显示位数不代表机械分辨率。发送与控制独立；默认周期下即便32位计数极值，一行仍能在20ms内发送完。若人为缩短 CONTROL_MS 至串口来不及发送，忙时不会排队保存新的遥测。

## 接线与约束

| 信号 | FPGA引脚 |
|---|---|
| clk / SW5 rst_n | M19 / AB3 |
| uart_tx / uart_rx | K20 / L20 |
| tb_pwm / tb_in1 / tb_in2 | V14 / AA17 / V15 |
| encoder_a / encoder_b | Y20 / AA20 |

电机接 XH1，对应 TB6612 的 B 桥。IO 使用 LVCMOS33，BANK4 供电跳线需为 3.3V。
CST 与 SDC 已加入工程。SDC 只声明真实50MHz时钟，没有给 PID 添加多周期或 false-path 例外；异步外部 UART/编码器走原模块同步逻辑，未假设未知外设 IO 延迟。

## 验证

详见 `VALIDATION.md`。`tests/tb_pid_motor.sv`为自检集成仿真，包含独立 PID 数学模型、物理 UART 接收/发送、命令异常、周期及积分检查；`tests/tb_pid_pipeline.sv`检查分拍延迟、随机整数运算、输入快照、忙时触发及各阶段取消。
残帧测试将计数器推进到100ms阈值，不是等待完整100ms；编码器反馈由测试夹具注入，不模拟机械系统。
